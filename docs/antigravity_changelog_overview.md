# Google Antigravity 最近更新概览 (2026年2月-3月)

以下是近期核心更新内容的概述：

### 🚀 核心新特性与改进 (Features & Improvements)
1. **多规则文件支持 (v1.20.5)**：现在 Agent 不仅能读取 `GEMINI.md`，还支持读取 `AGENTS.md` 中的规则（这非常契合您当前项目中的配置）。
2. **Auto-continue 变为默认 (v1.20.5)**：“自动继续”设置已被弃用，现在默认开启此功能。
3. **性能提升 (v1.20.5 & v1.15.8)**：显著改善了长对话的加载时间，并在底层优化了 Token 统计，修复了导致对话过早达到 Token 上限的 Bug。
4. **反馈功能升级 (v1.19.4)**：用户现在可以在提交反馈报告时附带屏幕截图。
5. **模型升级 (v1.19.4)**：提供全新的 **Nano Banana Pro 2** 模型支持。
6. **新的设置面板与资源下载 (v1.18.3)**：新增了模型和终端集成的设置界面，并支持下载 Artifacts（产物文件）。

### 🛡️ 账号与安全管理 (Account & Security)
* **账号申诉通道 (v1.19.6)**：为因违反服务条款而被封禁的账号引入了正式的申诉恢复流程 (Account Remediation Pathway)。
* **终端沙盒模式 (v1.15.6)**：为 MacOS 用户引入终端沙盒，防止 Agent 执行命令时破坏工作区以外的文件。
* **安全模式 (v1.11.17)**：强制人工审查 Agent 的所有行为，防止自动执行潜在的漏洞利用脚本。

### 🐛 关键 Bug 修复 (Crucial Fixes)
* **Windows 自动更新器修复 (v1.18.4)**：修复了 Windows 下无法检测新版本的问题（若停留在 1.16.5 或 1.18.3 需手动更新）。
* **内置浏览器修复 (v1.19.5)**：修复了导致浏览器无法启动的严重 Bug。
* **UI 与终端修复 (v1.20.5)**：修复了 Agent Manager 终端中的颜色对比度问题，以及旧 SSH 服务器实例的清理问题。

### 🗑️ 弃用与移除 (Deprecations)
* **移除命令支持 (v1.20.5)**：正式移除了传统的 Command（预设命令）支持。
